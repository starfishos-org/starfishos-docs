# StarfishOS Documentation

Research website for StarfishOS, a state-partitioned microkernel for CXL pods.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static site is emitted to `out/`. Pushes to `main` are automatically deployed
to [GitHub Pages](https://starfishos-org.github.io/starfishos-docs/).
